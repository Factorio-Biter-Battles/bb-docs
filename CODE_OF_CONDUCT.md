# Code of conduct

This repository follows the same rules as the Biter Battles server and its Discord. Short
version:

- **Be decent to each other.** Disagree with the text, not with the person who wrote it.
- **No harassment, slurs or personal attacks**, in issues, pull requests, commit messages or
  review comments. The same lines that get you jailed in game get your PR closed here.
- **Assume good faith.** Someone correcting your page is doing you a favour; someone
  defending a sentence usually has a reason you have not heard yet. Ask for it.
- **Keep it about Biter Battles.** This is not the place for politics, drama from other
  communities, or advertising.

Maintainers may edit, lock or close anything that breaks these rules, and may block repeat
offenders from the repository. Serious incidents also get reported to the server admins,
because it is the same community.

To report something, contact a maintainer listed in [CODEOWNERS](CODEOWNERS) — on GitHub, or
on the Biter Battles Discord. Reports are handled privately.
