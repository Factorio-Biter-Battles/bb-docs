## Phases (think in groups, not strict order)

- **Phase 1 — Automation**. Always first. Stop hand-crafting gears.
- **Phase 2 — Pre 17%**. Higher difficulty = faster to 17%. Get **grenades** before 17%.
  Group: grenades (military → logistic-sci → steel → military 2 — handcraft the 20 green sci
  needed); walls (steel-processing → stone-wall); building (logistics → electronics →
  fast-inserter → automation 2 → adv. material processing → steel-axe); other defense
  (gun-turret → PPD 1 → heavy-armor → stronger-explosives 1 → weapon-shooting-speed 1).
- **Phase 3 — Pre 50%**. Goal: walled, flamers, mil-sci + blue-sci flowing. Group: oil
  (engine → fluid-handling → oil-processing); flamers (flammables → flamethrower →
  refined-flammables 1+2); blue (plastic → adv-electronics → sulfur → blue). Only **50
  mil-sci** needed for flamethrower — handfeed if your mil-sci build lags. While waiting,
  queue defense upgrades: flamer dmg, stronger explosives, PPD, weapon-shooting-speed.

## Order if the enemy is rushing or difficulty ≥ Normal

automation → military → gun-turret → logistic-sci → steel-processing → military-2
(handcraft 20 green) → stone-wall → heavy-armor → logistics → electronics → fast-inserter →
steel-axe → PPD-1 → WSS-1 → automation-2 → mil-sci → stronger-explosives-1 → PPD-2 → WSS-2 →
adv. material processing → engine → fluid-handling → oil-processing → flammables →
**flamethrower** → refined-flammables-1 → refined-flammables-2.

## Order on a slower game (ITYTD, Piece of Cake)

Same path, slightly different early ordering: automation → military → gun-turret → logistics
→ logistic-sci → steel-processing → military-2 → stone-wall → electronics → fast-inserter →
steel-axe → heavy-armor → PPD-1 → WSS-1 → automation-2 → mil-sci → stronger-explosives-1 →
PPD-2 → WSS-2 → adv. material processing → engine → fluid-handling → oil-processing →
flammables → flamethrower → refined-flammables-1 → refined-flammables-2.

## Rules of thumb

- If you don't need it, don't research it — throw it instead.
- Don't throw early science when later sciences are being researched.
- Don't throw science actively feeding the labs.
- If nothing is researching, queue defense upgrades.
