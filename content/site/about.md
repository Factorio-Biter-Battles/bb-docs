Stats, votes, event details and ranks for the Free Biter Battles server.

## Server

Add us to favourites: `biterbattles.org:34197`

Hosted in Germany, on a machine dedicated to the game — the servers, the website, the bots
and the Discord integrations all run there.

## What you'll find here

- Live server stats, science leaderboards, ELO ranks and BB Bets prediction markets.
- Captain games history with full pick lists, winners, savefiles to download.
- Events & competitions tracking — including [BB Masters](http://bbmasters.net/) and
  [BB Champions](https://bbchampions.org/).
- In-game bot for stats and trading — type `askbot help` while playing.

## Open source

The game scenario is fully open source — pull requests welcome:
[github.com/Factorio-Biter-Battles/Factorio-Biter-Battles](https://github.com/Factorio-Biter-Battles/Factorio-Biter-Battles)
(GPL-3.0).

The documentation you are reading is open too, and lives in its own repository — the "edit
this page" link at the bottom of every page goes straight to it. The website's own
application code stays closed: it holds the server credentials, the Discord OAuth secrets
and the coins engine.

## Community

We are an open community **driven by players, for players**. Submit votes on Discord, jail
(or report) griefers, and chat / track game start–end events live on our Discord server.

Discord has Nitro boost — voice quality up to 128 kb/s for team comms. *We need admins — DM
us on Discord.*
